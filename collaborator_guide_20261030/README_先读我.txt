KnowBody 合作者交接包
======================

1. 先读 KnowBody_Collaborator_Guide.docx。
   HTML同内容版本：guide.html，可用浏览器直接打开。
   KnowBody_Collaborator_Guide.pdf用于固定排版预览。

2. 选图请打开 index.html。
   默认33张精选；可切到全部152张，按真机/仿真、任务、案例、关键词筛选。
   点击图片打开原分辨率文件。需先完整解压此包，保留目录层次。
   网页完全离线，不需要登录、服务端、CDN、网络或API。

3. 绘图用 assets/originals/ 下原图；不要从Word截图。
   assets/sequences/ 是指南时序图，catalog/sequences.json记录单帧构成与裁切。
   assets/diagrams/ 有PNG与原生SVG机制图；SVG文字/形状可继续编辑。
   catalog/assets.csv 可在Excel中筛选，JSON保留完整来源及hash。
   catalog/精选总览.pdf 便于快速浏览33张精选。
   reference_figures/ 中为已有总图PPT和Body/External参考PDF。

4. 当前架构锚定 v4-runtime37-20261030。
   三条仿真实验线独立积累经验；历史案例保留真实来源版本。
   真机图来自v9及此前开发素材，用于呈现身体/交互关系；其身份与当前v4实验链分开。
   evidence/ 保存公开案例摘要、精确知识和代码出处；不包含未公开思考过程。

本次仅整理既有资料，没有启动新仿真/真机动作，没有修改harness、经验库或论文。
