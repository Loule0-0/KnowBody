# KnowBody

**Know Your Body: A Continual Embodiment Harness for Direct VLM Control**

[Project Page](https://loule0-0.github.io/KnowBody/)

KnowBody makes action-relevant body relations explicit, queryable, and revisable while keeping the vision–language model frozen. The project page contains the current paper, method overview, real-robot results, and forthcoming demonstrations.
